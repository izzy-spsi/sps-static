Brainstorm
AI Concierge — Concept Notes
Working session — not final. For Izzy's review before locking into deck/video language.

What it is

A single, persistent AI relationship per resident (or per household) that sits on top of every EZLiving layer — real estate, furnishings, mobility, services, Cloud Closet — so the resident never has to know which vendor or system is behind a request. One conversation, one memory, everything handled.

Core Jobs

  • Household ops — package handling, dry cleaning pickup, utility issues, maintenance requests
  • Mobility dispatch — books EV/autonomous rides, hydrofoil trips, tracks arrival
  • Cloud Closet — "send me my winter coats" → routes physical retrieval automatically
  • Move-in / move-out — coordinates furnishing swaps, seasonal refresh, resident transitions
  • Community layer — building announcements, event RSVPs, neighbor-to-neighbor requests (optional)

Why it's a moat, not a feature

  • Every interaction trains a resident-specific memory — hard to replicate once a household is embedded
  • Turns a real estate transaction into a recurring, sticky relationship (subscription-like retention)
  • Natural upsell surface — the Concierge can recommend Cloud Closet upgrades, mobility packages, services
  • Positions EZLiving as an experience layer, not a property manager — much stronger investor narrative

Positioning options (pick one voice)

  • "Your home, on call." — warm, simple, consumer-friendly
  • "The OS for how you live." — platform/investor framing
  • "One relationship. Everything handled." — ties directly to the public video's closing line

Open questions for Izzy

  • Does the Concierge get a name/persona (like a "Jarvis for EZLiving"), or stay unbranded/invisible infrastructure?
  • Voice-first (phone call/Alexa-style) vs. text/app-first for MVP — which ships with the 9201 pilot?
  • Is this built in-house, or licensed/white-labeled (similar to the SPS "A.I.R." Phase 2 model already in motion for SPS members)?
  • Should the investor video give the Concierge a live on-screen demo moment, or keep it conceptual until it's real?
